# Steps to create a Django Project

1. Create a folder for the new project
2. Open VS Code and a terminal at that project
3. Create the virtual environment

    - Mac: python3 -m venv venv (The last parameter is optional is not mandatory to call it 'venv')
    - Windown: python -m venv venv

4. Activate the venv

    - Mac: source venv/bin/activate
    - Windows: .\venv\Scripts\activate

5. Install the required dependencies

    - Both OS: pip install django (pip3 if you're on a MAC)

6. Create the django project (One time only command)

    - Both OS: django-admin startproject NAME_FOLDER .
    Expectation is: config folder, venv folder and manage.py file

7. Update settings.py to recognize **static** and **templates** path
   Expectation is: templates and static folders are created

    7.1 Inside of static you can creat three subfolders called: js, css, and img

8.  Adding misc files: .gitignore, README.md
